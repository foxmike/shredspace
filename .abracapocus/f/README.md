## Goal

Close the full static audio path: routing, cross-feedback, safety, bypass, Hold, and complete processBlock integration, with the full loop tested in this phase. Source/DSP/RoutingEngine.h/.cpp: Parallel (both voices fed dry input, wet = level_A*out_A + level_B*out_B), A-into-B (input_B = cos(pi*cascade/2)*dry + sin(pi*cascade/2)*out_A) and the reversed B-into-A, with routing changes under a 30 ms wet-path crossfade and no bidirectional cascade loop; wet voice normalization N = sqrt(max(1, l_A^2 + l_B^2)), wet = (l_A*z_A + l_B*z_B)/N; global mixing Insert (dryGain = cos(pi*m/2), wetGain = sin(pi*m/2)) and Send (wet only). Cross-feedback in FeedbackController: feedback_L = g*((1-q)*z_L + q*z_R), feedback_R = g*(q*z_L + (1-q)*z_R) for q in [0,1] (q=0 independent, q=0.5 stereo average, q=1 ping-pong), eigenvalues g and g*(1-2q) so the 0.985 ceiling guarantees stability across the whole q range. Source/DSP/SafetyProcessor.h/.cpp with two layers: mandatory, never user-disableable - hard 0.985 feedback cap, NaN rejection, infinity rejection, DC blocker y[n] = x[n] - x[n-1] + R*y[n-1] with R = 0.995, invalid-state muting, bounded state reset, denormal handling; and the optional user-facing Safety RMS limiter - squared-energy state feedbackEnergy2[n] = alpha*feedbackEnergy2[n-1] + (1-alpha)*sample^2, level read as sqrt(max(energy2,0)+epsilon), threshold 0.90 linear, reduction = min(1, threshold/(energy+epsilon)), g_safe = min(0.985, g_requested*reduction), attack 2 ms, release 250 ms. Invalid-state response sequence: mute the affected wet output for the current block, reset lightweight filters/envelopes/detector states immediately, set an atomic safety-intervention flag, clear large delay buffers at a bounded block boundary or incrementally, never clear megabytes mid-block. Bypass in RoutingEngine: hard bypass fades the wet path out, retains dry, stops delay input, and clears the remaining tail after the transition completes; trails bypass stops new delay input via delayInput = (1 - bypassRamp)*input while the tail decays and dry continues; transitions are 20 ms and click-free. Hold in DelayVoice: on engage, new delay input goes to zero and the loop crossfades over 30 ms equal-power into a dedicated Hold path that bypasses HPF, LPF, Presence Guard, transient softening, saturation, and diffusion while retaining fractional delay, routing, stereo channel exchange, DC blocker, NaN/Inf rejection, the hard ceiling, and emergency safety; g_hold = 0.985 giving a long-decaying freeze whose tail does not progressively darken; release is click-free. processBlock in PluginProcessor composes: input gain g = 10^(G_dB/20), dry path preserved, per-block HostTiming acquisition, both DelayVoices, RoutingEngine, StereoProcessor, SafetyProcessor, global mix, output gain, across all three bus layouts with mono dry remaining center-equivalent and deterministic channel initialization, ScopedNoDenormals at top. Three serialized test files: tests/RoutingBypassTests.cpp (all topologies, click-free 30 ms routing transition, hard and trails bypass with dry preservation and no new input under trails, insert/send behavior); tests/SafetyHoldTests.cpp (impulses, full-scale tones, silence, denormal-range values, NaN, infinity, maximum feedback, DC - confirming no invalid output, no runaway, no hang, safety flag published, mandatory safety active with the RMS limiter disabled; Hold kills input, bypasses tone processing so the held tail stays spectrally stable, caps at 0.985, releases click-free); tests/StaticSignalPathTests.cpp (cross-feedback channel movement and stability at q = 0, 0.5, 1; mono-mono, mono-stereo with valid deterministic stereo output and centered dry, stereo-stereo; end-to-end impulse through the complete path; no output at zero tail).
