# g

## Goal

Implement the performance analyzer at a fixed internal 48000 Hz analysis rate so detection behavior is equivalent at every host rate. Source/Analysis/AnalysisResampler.h/.cpp: analysis-band low-pass before rate conversion so content above the useful band (approximately 150 Hz - 8 kHz) cannot alias; a stateful converter handling both upsampling 44.1 kHz to 48 kHz and downsampling 88.2/96/176.4/192 kHz to 48 kHz, preserving state across blocks, using preallocated buffers and a phase accumulator, producing the correct long-term output rate, allocating nothing in processing, affecting only the analysis path, adding no reported latency to dry or wet audio. Source/Analysis/PerformanceAnalyzer.h/.cpp: analysis energy for stereo energy[n] = sqrt((L^2 + R^2)/2 + epsilon) and abs(x) for mono; fast (2 ms) and slow (60 ms) envelopes via alpha = exp(-1/(tau * 48000)); time-domain novelty = max(0, 20*log10((fast+eps)/(slow+eps))). Source/Analysis/OnsetDetector.h/.cpp: causal STFT with 512-sample Hann window (0.5*(1 - cos(2*pi*n/(N-1)))), hop 256, at the fixed rate (window 10.6667 ms, hop 5.3333 ms, bins 93.75 Hz), preallocated FFT storage; positive log-magnitude spectral flux averaged over bins spanning approximately 150 Hz - 8 kHz: (1/K)*sum(weight_k * max(0, log(|X_m[k]|+eps) - log(|X_m-1[k]|+eps))); per-feature adaptive normalization with running mean and running absolute deviation, z_i = max(0, (v_i - mean_i)/(deviation_i + eps)) over z_time (normalized time novelty), z_flux (normalized flux), and z_energy (normalized positive deviation of slow-envelope level in dB); onsetScore = sigmoid(w_time*z_time + w_flux*z_flux + w_energy*z_energy - threshold) with sigmoid 1/(1+exp(-x)) and initial weights w_time 0.35, w_flux 0.50, w_energy 0.15; acceptance via threshold crossing, local-maximum selection, noise-gate qualification, and a 25 ms refractory interval. Source/Analysis/DensityEstimator.h/.cpp: accepted onset timestamps in a fixed-size real-time-safe ring buffer; eventRate = onsetCount over the density window divided by the window; u = clamp((eventRate - densityStart)/(densityFull - densityStart), 0, 1); density = 3u^2 - 2u^3. Source/Analysis/SustainEstimator.h/.cpp: activity = smoothstep((inputLevel_dB - gate_dB)/gateWidth_dB); sustainTime = smoothstep((timeSinceLastOnset - sustainStart)/(sustainFull - sustainStart)); sustain = activity * sustainTime * (1 - density) * (1 - smoothedOnsetActivity), a continuous confidence, never a hard technique classification; plus the phrase-gap detector requiring recent prior activity, envelope below gate, and no accepted onset for the gap duration, output shaped by attack/hold/release, generating no audio itself. Source/Analysis/AdaptiveController.h/.cpp: C_target = clamp(densityWeight*density + onsetWeight*smoothedOnsetActivity, 0, 1); B_target = clamp(sustainWeight*sustain + gapWeight*phraseGap, 0, 1) * (1 - contraction); DEFINITION scales contraction, BLOOM scales bloom; each destination gets separate attack and release smoothing, never one shared envelope; the three adaptive modes exactly: Off forces contraction = bloom = 0 with telemetry allowed but zero audible effect (sample-identical to the static path within floating-point determinism); Level is traditional envelope-based wet ducking only (input activity, fast envelope, slow release, affecting wet level reduction and return exclusively - no flux, density, sustain, gap, tail, tone, width, or softening); Articulation is the full fusion engine; destination deltas computed per voice weighted by adaptiveRole in [0,1]: wet dB delta = -role*C*wetReduction_dB + role*B*wetLift_dB; T60 octave delta with T60_eff = T60_base * 2^(-role*C*tailReductionOct + role*B*tailExpansionOct) and feedback recomputed then capped at 0.985; LPF_eff = LPF_base * 2^(-role*C*toneDarkeningOct + role*B*toneOpeningOct); width_eff = clamp(base - role*C*widthReduction + role*B*widthExpansion, 0, 2); softening_eff = clamp(base + role*C*softeningIncrease, 0, 1); diffusion_eff = clamp(base + role*B*diffusionIncrease, 0, 0.40). tests/AnalysisTests.cpp: synthetic signals (isolated impulses; impulse trains at 2, 4, 8, 12, 16, 20 events/second; sustained sine; vibrato; amplitude tremolo; legato-like frequency changes; noise bursts; distorted guitar-like signals; gated silence) verifying density rises monotonically with event rate, sustained input develops sustain confidence, silence triggers phrase gap only after prior activity, vibrato does not continuously retrigger onsets, sub-gate noise does not trigger bloom, and the same material rendered at 44.1, 48, 96, and 192 kHz host rates produces equivalent analysis results within documented numerical tolerance (exact sample identity is not required after rational rate conversion).

## Notes

- Async: Wave 1: g.1 (AnalysisResampler) creates the fixed-rate front end alone. Wave 2: g.2 (PerformanceAnalyzer) depends on g.1. Wave 3: g.3 (OnsetDetector), g.4 (DensityEstimator), and g.5 (SustainEstimator with phrase gap) run in parallel with disjoint files, all depending on g.2. Wave 4: g.6 (AdaptiveController) depends on g.3, g.4, g.5. Final wave: g.7 creates tests/AnalysisTests.cpp and registers all Analysis sources plus the test file in CMakeLists.txt (g.7 depends on g.6). CMakeLists.txt is owned only by g.7 in this phase.
- Risk: High-gain distortion flattens amplitude transients, so the fused detector must never rely on envelope novelty alone; the flux weight is the largest for that reason. Fixed-rate analysis is the sample-rate-invariance guarantee: FFT size and hop must never scale with host rate. All analyzer outputs are continuous confidences.
