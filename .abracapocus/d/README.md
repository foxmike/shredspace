# d

## Goal

Implement the repeat tone chain and integrate its first four stages into DelayVoice in the binding order (fractional read, HPF, LPF, Presence Guard, transient softener, with saturation and diffusion slots reserved for phase e, then feedback tap). Source/DSP/RepeatToneProcessor.h/.cpp: RBJ biquads with shared values omega0 = 2*pi*f0/Fs and alpha = sin(omega0)/(2*Q), Q = 0.70710678; low-pass b0=(1-cos omega0)/2, b1=1-cos omega0, b2=b0, a0=1+alpha, a1=-2 cos omega0, a2=1-alpha; high-pass b0=(1+cos omega0)/2, b1=-(1+cos omega0), b2=b0, a0=1+alpha, a1=-2 cos omega0, a2=1-alpha; peaking with A=10^(G_dB/40), b0=1+alpha*A, b1=-2 cos omega0, b2=1-alpha*A, a0=1+alpha/A, a1=-2 cos omega0, a2=1-alpha/A; all normalized by a0; coefficients computed in double, audio in float, cutoff and gain smoothed, coefficients updated at a bounded control rate, no coefficient-object allocation on the audio thread, no linear interpolation between unrelated coefficient sets. Source/DSP/PresenceGuard.h/.cpp: band-pass around the presence frequency (1.5-6 kHz), squared-RMS state energy2[n] = alpha*energy2[n-1] + (1-alpha)*presence^2 (carrying energy2 as state, computing sqrt(max(energy2,0)+epsilon) only when reading so epsilon does not accumulate), level_dB = 20*log10(energy+epsilon), excess u = clamp((level_dB - threshold_dB)/kneeWidth_dB, 0, 1), smoothstep 3u^2 - 2u^3, cut_dB = -maxCut_dB * smoothed value driving a negative peaking filter; internal defaults threshold -24 dBFS, knee 12 dB, detector attack 5 ms, release 120 ms; user maximum cut 0-12 dB; FOCUS, DEFINITION, and Adaptive Role may raise the effective maximum cut. Source/DSP/RepeatTransientSoftener.h/.cpp: complementary high-band extraction z_high = HPF(z), z_low = z - z_high guaranteeing exact reconstruction at unity gain; crossover default 2500 Hz, expert range 1000-6000 Hz; fast/slow envelopes on abs(z_high) with time constants 1.5 ms and 35 ms via alpha = exp(-1/(tau*Fs)); transient = max(0, (fast-slow)/(slow+epsilon)); attenuation_dB = -maxAttenuation_dB * clamp(transient,0,1) with gain = 10^(attenuation_dB/20) applied only to the high band, output z_low + gain*z_high; Attack Softening 0-100% maps to 0-12 dB maximum high-band attenuation. Integration wires HPF, LPF, PresenceGuard, and the softener into DelayVoice's loop in binding order. tests/RepeatChainTests.cpp: HPF/LPF/peaking magnitude responses against RBJ expectations; softener bit-transparent within floating-point tolerance at zero amount, high-band attacks reduced and low-band body preserved at nonzero amounts; guard applies no cut below threshold, smoothly increasing cut above, respects maximum cut, and shows no epsilon-accumulation bias at steady state.

## Notes

- Async: Wave 1: d.1 (RepeatToneProcessor), d.2 (PresenceGuard), and d.3 (RepeatTransientSoftener) run in parallel with disjoint files. Wave 2: d.4 integrates the three modules into DelayVoice.h/.cpp in the binding chain order and registers new sources in CMakeLists.txt (d.4 depends on d.1, d.2, d.3). Final wave: d.5 creates tests/RepeatChainTests.cpp and registers it in CMakeLists.txt (d.5 depends on d.4, serializing the CMakeLists.txt write).
- Risk: All filters sit inside the feedback loop, so coefficient zippering compounds across repeats; the control-rate update rule with smoothed inputs is mandatory, not stylistic. The complementary-subtraction split is what guarantees the softener colors nothing at zero setting; a materialized task substituting a crossover pair without the subtraction identity is wrong.
