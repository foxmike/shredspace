# c

## Goal

Implement timing and the core delay engine. Source/DSP/FractionalDelay.h/.cpp: third-order Lagrange interpolation with coefficients L_minus1 = -mu*(mu-1)*(mu-2)/6, L_0 = (mu+1)*(mu-1)*(mu-2)/2, L_1 = -(mu+1)*mu*(mu-2)/2, L_2 = (mu+1)*mu*(mu-1)/6 for fractional position mu in [0,1); maximum buffers of 8.25 seconds per channel allocated in prepare and never resized in processing; every final read position clamped to [8 samples, 8.25 seconds]; per-sample fractional reads; multiple simultaneous read heads to support Smooth transitions; bounded modulation offsets; deterministic reset. Smooth mode: two read heads r_old at D_old and r_new at D_new combined by equal-power crossfade r = cos(pi*lambda/2)*r_old + sin(pi*lambda/2)*r_new with lambda ramping 0 to 1 over the glide time (glide range 5-1000 ms), producing no intentional pitch bend. Bend mode: one read position ramped D[n] = D_start + lambda[n]*(D_target - D_start), with playback-rate factor p(t) = 1 - dD/dt so decreasing delay raises pitch; Bend is exempt from the modulation pitch cap. Source/DSP/DelayTimeController.h/.cpp: owns time modes Milliseconds (D_samples = Fs*T_ms/1000), HostSync (T_quarter = 60/BPM, T = ratio*T_quarter, divisions Whole/Half/Quarter/Eighth/Sixteenth with dotted x1.5 and triplet x2/3), and Tap (median of a fixed K=5 interval history, intervals outside 100-3000 ms rejected); consumes the HostTiming POD struct defined in its header { double bpm; bool bpmValid; bool isPlaying; std::int64_t samplePosition; } which the processor fills once per block - DSP modules never query the host; when BPM is invalid, retain the last valid BPM, falling back to 120 BPM if none was ever received, never jumping to zero or undefined delay; computes per-voice targets T_voice = T_base*ratio + fineOffset (+ modulation and stereo offset applied downstream) and issues Smooth/Bend transition requests for large changes including host-tempo jumps, scene changes, and profile changes. Source/DSP/FeedbackController.h/.cpp: T60-derived feedback g_requested = 10^(-3*T/T60_voice) with T60_voice = T60_global * tailScale_voice, always returning g_final = min(g_requested, 0.985); the 0.985 hard ceiling is unconditional including Hold. Source/DSP/DelayVoice.h/.cpp: composes fractional delay, time-controller targets, and feedback into one stereo voice with the write path write = input + feedback. tests/DspCoreTests.cpp: impulse first-repeat placement at round(Fs*T) for 44.1, 48, 88.2, 96, and 192 kHz; fractional positions against independently computed Lagrange values; clamp tests proving negative effective time (short ratio plus negative fine offset) clamps to 8 samples and maximum clamps to 8.25 s; T60 decay measuring 20*log10(A(T60)/A(0)) approximately -60 dB within tolerance; tap median rejecting one outlier; BPM fallback behavior.

## Notes

- Async: Wave 1: c.1 (FractionalDelay with Smooth/Bend read-head machinery), c.2 (FeedbackController), and c.3 (DelayTimeController with the HostTiming POD) run in parallel with disjoint files. Wave 2: c.4 (DelayVoice) composes all three (c.4 depends on c.1, c.2, c.3). Final wave: c.5 creates tests/DspCoreTests.cpp and registers all new DSP sources plus the test file in CMakeLists.txt (c.5 depends on c.4). CMakeLists.txt is owned only by c.5 in this phase.
- Risk: The Lagrange coefficients, the [8 samples, 8.25 s] clamp, and the 0.985 ceiling are correctness-critical for every later phase and must appear verbatim in materialized tasks. Smooth must not bend pitch and Bend must; the distinction is a product feature, not an implementation detail.
